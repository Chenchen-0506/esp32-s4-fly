# ESP32-S3 自研四旋翼无人机（固件仓库）

从零自研四旋翼无人机固件。ESP32-S3 主控，Arduino IDE 开发。

## 硬件（450mm X 型大机）

> 完整硬件清单与引脚分配说明见 **[HARDWARE.md](HARDWARE.md)**（v0.22，含数传引脚与可更换说明、磁偏角自动识别）

- 主控：ESP32-S3 DevKitC N16R8（SPI：ICM-20948 / I2C：BMP280 + 罗盘 / UART：BN-880 GPS / iBus：GPIO18（FS-iA6B 接收机））
- 动力：2212 KV920 ×4 + 30A BLHeli 电调 ×4 + 1045 桨 + 4S 3000mAh
- 传感器：ICM-20948 九轴（SPI）+ BMP280 气压计（I2C）+ BN-880 GPS/罗盘（UART+I2C）
- 遥控：FlySky FS-i6 + FS-iA6B 接收机（iBus 19200）：CH5 解锁开关、CH6 返航开关

## 目录结构与功能模块约定

每个里程碑（M1~M7）是一个**独立 Arduino 工程文件夹**，可直接用 Arduino IDE 打开烧录，互不依赖，方便按阶段回档。

```
esp32 S3/
├── esp32_board_check/        # 板子自检（N16R8 真伪 + 心跳）
├── esp32_sensor_check/       # 传感器自检（BMP280 + GPS NMEA）
├── M1_attitude_sensor/       # M1：ICM-20948 姿态解算（Mahony 6 轴）
├── M2_simulation/            # M2：刚体动力学 + 串级 PID 仿真
├── M3_remote_pwm/            # M3 备选：遥控 PWM 解析
├── M3_remote_sbus/           # M3：遥控 SBUS 解析
├── M4_esc_test/              # M4：电调校准 + 单电机测试
├── M5_gps_test/              # M5：GPS 定位测试
└── M6_full_flight/           # M6/M7：完整飞控（主程序 + src/ 功能模块）
```

**功能模块规范（M6 起）**：每个 sketch 文件夹下的 `src/` 子目录按功能拆分，一个功能一个 `.h/.cpp` 对，由主 `.ino` 引用。Arduino IDE 会自动编译 `src/` 下的代码，无需额外配置。

```
M6_full_flight/
├── M6_full_flight.ino        # 主程序：setup/loop、状态机、解锁、混控、返航
└── src/
    ├── ICM20948.h/.cpp       # 九轴 IMU 驱动（SPI）+ Mahony 姿态 + 零偏校准
    ├── BMP280.h/.cpp         # 气压计驱动（I2C）+ 相对高度
    ├── GPS.h/.cpp            # BN-880 NMEA 解析（定位/卫星/经纬度）
    ├── MAG.h/.cpp            # BN-880 内置罗盘（航向读取 + 自动磁校准 + 磁偏角自动识别）
    ├── RTL.h/.cpp            # 返航状态机（手动/失控自动返航）
    ├── SBUS.h/.cpp           # 遥控接收解析（iBus/FS-iA6B，兼容旧接口）
    ├── PID.h/.cpp            # 串级 PID 控制器
    ├── Motors.h/.cpp         # 4 路电机 PWM 输出
    ├── ALTHOLD.h/.cpp        # 定高 + 悬停（CH7）
    ├── WAYPOINT.h/.cpp       # 多航点航线（最多 8 点，逐点爬升+飞抵）
    ├── POSHOLD.h/.cpp        # 位置保持（GPS 悬停，参考 ArduPilot Loiter）
    ├── VERTEST.h/.cpp        # 垂直融合（1D 互补：加速度预测 1kHz + 气压修正 10Hz）
    ├── LOGGER.h/.cpp         # 黑匣子（RAM 环形 512 行 + LittleFS 落盘，串口 D 导出）
    ├── TELEMETRY.h/.cpp      # WiFi 仪表盘（softAP 热点，姿态/高度/航向/GPS/RC/电机）
    ├── LINK.h/.cpp            # 433MHz 数传链路（UART1：10Hz 遥测上行 + WP/D 命令下行）
    └── MAG_DECL_TABLE.h      # 磁偏角全球查表（NOAA WMM，10° 网格）
```

### 功能明细（由下而上按模块说明）

### 遥控信号质量（RSSI，v0.22）

- iBus 协议本身不含 RSSI 字段，采用**帧接收率**作为信号质量：最近 1 秒实际收到帧数 / 期望帧数（约 130 帧/s），0~100%
- 7:3 平滑防抖；无帧即失控（>1s）时质量归 0，与失控缓降/返航联动
- 地面站遥控通道卡显示**信号条**（≥70 绿 / 40~70 黄 / <40 红），弱信号会在地面站声音报警中提醒

### 解锁 / 上锁（CH5 开关）

- **解锁**：油门最低（<1050）+ CH5 拨高保持 2 秒；解锁瞬间重新记录地面气压并归零垂直融合（防气压漂移导致高度基准偏）
- **home 记录**：起飞后 GPS 定位**连续 1 分钟**自动记录当前位置为 home（解锁瞬间不记录）
- **上锁**：CH5 拨低，电机立即停转

### 返航（CH6 手动 / 失控自动，120m 巡航）

- **CH6 拨高**：进入手动返航（需 GPS 定位 + home 已记录，否则拒绝并提示）
- **遥控丢失**（iBus >1 秒无帧）：自动返航；**无 GPS 定位时进入怠速缓降**（GLIDE：油门 1150 缓慢降落，触地或 15s 超时自动上锁，v0.19.1）
- 返航流程：爬升到 **120m**（RTL_ALT）→ 机头对准 home 飞行（罗盘航向 + 距离 P 控制）→ 距 home <5m（RTL_NEAR）缓降 → 触地自动上锁
- 手动返航在爬升/飞行阶段可拨低 CH6 退出；降落阶段禁止退出（防悬空）
- 失控触发的返航不可中途退出；**已进入降落段时失控不打断，继续降落（禁止重爬 120m）**
- 返航高度/垂速由**垂直融合**（VERTEST）提供：加速度 1kHz 预测 + 气压 10Hz 修正

### 定高 / 悬停（CH7 开关）

- **CH7 拨高**：进入定高 + 悬停模式（需 GPS 定位）
  - 高度保持：定高 PID（悬停油门自动学习，10 秒持久化到 NVS，下次开机自动加载）
  - 位置保持：位置误差→倾角（死区 1.5m 压制 GPS 噪声，限幅 15°），摇杆=移动悬停目标点
- **CH7 拨低**：退出，恢复纯手动

### 起飞检查清单（v0.22）

- 地面站「起飞检查清单」卡逐项实时核对：**GPS 定位 / 卫星数量（≥8）/ HOME 记录 / 磁校准完成 / 遥控信号（≥70%）**
- 全部通过显示「可以起飞」，否则给出具体拦阻项（如 GPS 未定位=禁止起飞、磁校准未做=提示 CH6 拨高 3 秒）
- 磁校准完成标志（`magCal`）由固件 NVS 持久化：做过一次即长期有效，掉电不丢
- **声音报警**（Web Audio，可关闭）：失控缓降急促蜂鸣、连接断开提示音、数据超时提醒、磁校准完成确认音

### 磁校准（返航前必须，全自动）

- 未解锁 + 油门最低 + **CH6 拨高 3 秒** → 进入自动校准模式
- 水平端平机身，慢速旋转整机 2~3 圈 + 8 字，**30 秒自动完成**（或拨低 CH6 提前结束）
- 校准值自动存入 ESP32 NVS（掉电不丢），下次开机自动加载
- **磁偏角自动识别**（v0.21）：内置 NOAA WMM 全球查表（`src/MAG_DECL_TABLE.h`，10° 网格 + 双线性内插），GPS 定位后自动按经纬度更新（10s 节流，变化 >0.2° 写 NVS），去哪飞都不用改；无 GPS 时用上次保存值。遥测 `magDecl` 字段可查看当前值

### 黑匣子（LOGGER，v0.11）

- 飞行数据实时写入 RAM 环形缓冲（512 行），每 60 秒落盘 Flash（LittleFS `/log.txt`），**上锁/返航完成立即落盘**（断电最多丢 1 分钟）
- 串口监视器输入字母 **`D`** → 导出全部日志
- 首次使用 LittleFS 自动格式化分区（正常现象）

### GPS 多航点航线飞行（WAYPOINT，v0.17）

- WiFi 仪表盘页面升级为**航线面板 + 自绘航图**：
  - 输入坐标点「添加航点」（最多 **8 个**），列表实时显示（编号/坐标/高度）
  - 点「开始航线」→ 飞机自动按 **A→B→C 顺序**逐点飞行，每个航点先爬升到该点高度再直线飞抵
  - **飞完最后一个航点后悬停等待**（不自动返航），随时可遥控接管或点「取消」
  - **自绘俯视航图**：以 home 为中心（北向上，SVG 雷达图），实时显示飞机位置（绿三角）、航点（蓝/黄圆+编号）、连线轨迹与半径标尺——**无需外网，热点下可用**
- 控制逻辑复用 RTL 的飞向目标算法：机头对准目标方位 + 距离 P 倾斜（最大 15°），高度三段式保持
- 安全规则：**遥控任意摇杆偏离中位立即退出航线**回手动；上锁/失控/返航（CH6）触发时航线自动取消（返航优先）
- 网页命令路由（WiFi 页面 AJAX 调用）：
  - `/wp?cmd=add&lat=..&lon=..&alt=..` 添加航点
  - `/wp?cmd=clear` 清空航线；`/wp?cmd=start` 开始；`/wp?cmd=stop` 停止
  - `/api` 遥测 JSON，新增 `wpIndex`/`wpTotal`/`wpList`（全部航点坐标）与 `wp`（剩余距离）
- 命令关键字大小写均可（WiFi 页面小写与数传 `WP:ADD` 大写兼容）
- 注意：飞行中**热点无外网**，不能加载在线地图；查坐标方法：起飞前用手机地图 App（有网时）搜好目标点抄经纬度填入

- WiFi 仪表盘页面新增**航点卡**：输入目标纬度/经度/高度 → 点击「开始航点」→ 飞机自动爬升到设定高度并直线飞抵目标（**到点后悬停等待**）
- 控制逻辑复用 RTL 的飞向目标算法：机头对准目标方位 + 距离 P 倾斜（最大 15°），高度三段式保持
- 状态机：`WP_CLIMB`（爬升）→ `WP_FLY`（直线飞行）→ `WP_ARRIVED`（到点悬停）
- 安全规则：**遥控任意摇杆偏离中位立即退出航点**回手动；上锁/失控/返航（CH6）触发时航点自动取消（返航优先）
- 网页命令路由：`/wp?cmd=start&lat=..&lon=..&alt=..`（单点直飞）、`/wp?cmd=stop`（停止）；`/api` 新增 `wp` 字段（剩余距离，-1=未激活）
- 注意：飞行中**热点无外网**，不能加载在线地图，坐标按页面提示手输（可从起飞前页面显示的当前位置参考微调）

### WiFi 实时仪表盘（TELEMETRY，v0.13 升级）

- 开机自动开热点 **`S4Fly-Telemetry`**（密码 `12345678`）
- 手机连热点 → 浏览器打开 **`http://192.168.4.1`**：姿态球 + 高度/航向/GPS/遥控通道/电机油门仪表（500ms 刷新），日志滚动可下载
- 完全无需 USB，适合外场悬停/试飞观测

### 433MHz 数传链路（LINK，v0.19 落地）

- **接线**（机载）：主控 `GPIO14(TX)` → 机载数传模块 RX；主控 `GPIO15(RX)` ← 机载数传模块 TX；数传 5V/GND 供电（与分电板 UBEC 同源）
- **波特率**：`57600` 8N1（UART1，引脚宏在 `src/LINK.h`，与地面端默认一致）
- **上行遥测**：10Hz 输出 JSON 行，字段与 `/api` 完全一致（`t/armed/mode/rssi/magCal/roll/pitch/yaw/alt/vspd/spd/rc[7]/fix/sats/lat/lon/home/homeLat/homeLon/hdg/magDecl/wp/wpIndex/wpTotal/wpList[8]/mot[4]`，vspd=垂直速度 m/s、spd=水平地速 m/s GPS 差分、magDecl=当前磁偏角 deg）
- **下行命令**：地面站发一行即可
  - `WP:ADD,lat,lon,alt` 添加航点（alt 省略默认 30m）
  - `WP:CLEAR` 清空航线 / `WP:START` 开始 / `WP:STOP` 停止
  - `D` 回传最近 10 行黑匣子日志
- **USB 同步输出**：同一份 JSON 也打到 `Serial`（115200），Type-C 连电脑后地面站用 **Web Serial** 直读，无需数传即可联调
- **模块可更换**：数传接 UART1（GPIO14/15 + 5V/GND，57600），非焊死。任何 433MHz 数传（3DR / SDR X6 等）按上表接线即可替换，**无需改固件**；更换时注意 TX↔RX 交叉、GH1.25 线序防反接
- **路线**：数传联调通过后，WiFi 仪表盘（TELEMETRY Web 服务）将删除，**只留数传**（用户已确认）
- **网页记录与导出（分析通道，v0.20）**：地面站收到遥测自动记录（电脑端 Web Serial / 手机端共享均支持），飞行后点 **“导出数据(CSV)”** 生成 `S4Fly_flight_时间戳.csv`（含 vspd/spd，Excel 或脚本可直接分析）；**不再依赖机载完整日志下载**——黑匣子仅作机载兜底


## 地面站使用教程（数传网页）

### 文件位置

工程 `groundstation/` 目录四件套（均为自包含文件，不依赖外网库）：

| 文件 | 用途 |
|---|---|
| `S4Fly地面站.html` | 电脑端地面站（Chrome/Edge 打开即用） |
| `手机共享页面.html` | 手机端地面站（由电脑端共享转发） |
| `启动共享服务器.bat` | 双击启动局域网共享服务器（供手机访问） |
| `share_server.py` | 共享服务器本体（由 bat 调用，端口 8787） |

### 两种连接方式（注意波特率不同）

| 方式 | 适用 | 电脑上操作 | 波特率 |
|---|---|---|---|
| **USB Type-C 直连** | 联调 / 无数传 | 数据线连电脑 → 地面站点「连接串口」选 COM | **115200** |
| **433 数传** | 外场飞行 | 地面数传 USB 插电脑（装驱动出 COM）→ 点「连接串口」 | **57600**（默认） |

> 切换连接方式时必须同步改波特率：USB 联调 115200，数传 57600。USB 同路遥测输出在固件 `Serial`（115200），数传在 `LINK` UART1（57600），两路数据内容完全一致。

### 界面速览

- **顶栏**：波特率 / 连接串口 / 数据链路指示灯 / 上锁指示灯 / 状态徽章 / 模式（MANU）/ 共享到手机
  - 数据链路指示：`等待数据 → 数据正常（绿）/ 数据超时(Ns) / 无数据，检查数传`
- **主体**：姿态（横滚/俯仰/偏航）、高度（相对起飞点，120m 上限）、垂直速度、航向、距 HOME、剩余航点、地图（高德/卫星切换、跟随/自由、清空轨迹）、电机油门 M1~M4
- **底部**：显示原始数据（日志窗默认展开）/ 暂停 / 导出数据(CSV) / 清空记录

### 状态徽章含义

| 徽章显示 | 含义 |
|---|---|
| 未连接（灰） | 未收到遥测数据 |
| GPS搜索中 N星 | 未解锁，正在搜星 |
| 待起飞 | 已定位、未解锁 |
| 无GPS定位 | 已解锁但定位丢失（危险状态，失控将进入缓降） |
| 手动飞行 | 手动模式飞行中 |
| 磁校准中 | 未解锁+油门最低+CH6 拨高 3 秒触发，转动机身 30s 自动完成 |
| 返航中 爬升中 / 直线返航 / 下降降落 / 已降落 | RTL 各阶段（CH6 或失控触发） |
| 航点飞行 爬升 / 飞向航点 / 到点悬停 | 航线各阶段 |
| 失控缓降 | 无 GPS 失控，怠速缓降触地上锁 |
| 位置悬停 | CH7 定高+悬停模式 |

### 航点操作（多航点航线）

1. 连接后，航点面板输入 **纬度 / 经度 / 高度**（逗号分隔）→「添加」（最多 8 点）
2. 「开始航线」→ 飞机逐点爬升+飞抵，飞完最后一个航点悬停等待
3. 「取消」立即停止；任意摇杆偏离中位自动退出回手动
4. 「请求日志」= 向飞控发送 `D`，回传黑匣子最近日志

### 共享到手机

1. 电脑双击 **`启动共享服务器.bat`**（黑色终端保持打开，显示 `http://(电脑IP):8787`）
2. 电脑端地面站点「共享到手机」（显示"共享中..."）
3. 手机连**同一 WiFi**，浏览器打开 `http://电脑IP:8787` 即手机端地面站
4. 手机端与电脑端同一数据源（电脑转发），两端均支持地图、航点、CSV 导出

> 提示：提示"没找到服务器：请先双击「启动共享服务器.bat」"时，先启动 bat 再点共享。

### 飞行数据记录与导出（分析通道）

- 连接后遥测**自动记录**（内存上限 20000 条 ≈ 33 分钟 @10Hz）
- 飞行后点「**导出数据(CSV)**」→ 生成 `S4Fly_flight_时间戳.csv`
- **25 列**：`t, armed, mode, roll, pitch, yaw, alt, vspd, spd, fix, sats, lat, lon, home, homeLat, homeLon, hdg, magDecl, wp, wpIndex, wpTotal, m1, m2, m3, m4`（含磁偏角，Excel/脚本直接分析）
- 「清空记录」开始新一轮记录

### 常见问题

| 现象 | 处理 |
|---|---|
| 点「连接串口」无弹窗 | 必须 Chrome/Edge（Web Serial 不支持其他浏览器） |
| 连接失败 | 检查 CP210x 驱动、端口是否被占用、换数据线 |
| 数据超时(Ns) | 检查数传供电（5V/GND）与 TX↔RX 交叉 |
| 波特率不对 | USB 用 115200，数传用 57600 |
| 手机打不开共享页 | 确认电脑与手机同一 WiFi、bat 终端未关闭、防火墙放行 8787 |

### 参数调节

- 返航参数集中在 `src/RTL.h`；定高/悬停参数在 `src/ALTHOLD.h` / `src/POSHOLD.h`；垂直融合在 `src/VERTEST.h`；内环 PID 在 `src/PID.h`，外环角度增益在主程序开头 `ANGLE_P_*`
- 首次试飞建议保守值，按串口/黑匣子数据逐步微调


## 快速开始（安装教程）

从零到烧录，约 10 分钟。

### 1. 安装 Arduino IDE

官网下载 2.x（实测 2.3.x），Windows 一路下一步。IDE 1.x 也可用，但推荐 2.x。

### 2. 安装 ESP32 核心

1. **文件 → 首选项 → 附加开发板管理器网址**，填入：
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. **工具 → 开发板 → 开发板管理器** → 搜索 `esp32` → 安装 **esp32 by Espressif 3.3.x**（实测 3.3.11）
   - 下载慢/失败：多试几次，或给网络加速后重试（安装包走 GitHub Release）

### 3. 选择板型（关键，选错烧录/运行异常）

**工具 → 开发板 → ESP32S3 Dev Module**，再核对：

| 工具菜单项 | 值（本机 N16R8） |
|---|---|
| Flash Size | 16MB(128Mb) |
| PSRAM | OPI PSRAM |

### 4. 打开工程并编译烧录

1. **文件 → 打开** → 选 `M6_full_flight` 文件夹（`.ino` 在根目录，`src/` 子模块自动编译，无需任何配置）
2. Type-C 数据线连电脑（板载 CP2102N USB-UART：若设备管理器无 COM 口，先装 **CP210x 驱动**）
3. **工具 → 端口** → 选对应 COM
4. 点「**→**」上传；首次烧录完打开**串口监视器（115200）**即可看到 10Hz 遥测 JSON

### 5. 各里程碑工程（回档学习）

每个 M 文件夹是**独立 Arduino 工程**，互不依赖：按 `M1 → M2 → … → M7` 顺序打开对应文件夹编译烧录即可（M6_full_flight 为完整飞控）。每个里程碑完成即打 `vX.Y` 标签，`git checkout v0.4-M7` 即可回档任一阶段。

### 6. 后续接线与硬件

所有引脚分配、BOM 清单、数传/传感器接线见 **[HARDWARE.md](HARDWARE.md)**；遥控通道功能：CH5 解锁、CH6 返航/磁校准、CH7 定高/悬停。

## 软件依赖

### 开发环境

| 软件 | 版本 | 用途 |
| --- | --- | --- |
| Arduino IDE | 2.x（实测 2.3.x） | 主开发环境，打开各工程文件夹直接编译烧录 |
| ESP32 核心（esp32 by Espressif） | 3.3.x（实测 3.3.11） | Arduino IDE 库管理器安装，提供 `esp32:esp32:esp32s3` 板型 |
| arduino-cli | 1.5.x | 可选，命令行编译/验证用（Arduino IDE 内置） |

### 板型选择

- **开发板**：`ESP32S3 Dev Module`（FQBN：`esp32:esp32:esp32s3`）
- **Flash Size**：16MB（N16）
- **PSRAM**：OPI PSRAM（R8）

### 第三方库

**零第三方依赖**。全部代码仅使用 ESP32 核心自带的库：

- `<Arduino.h>`、`<SPI.h>`、`<Wire.h>`、`<math.h>`

IMU（ICM-20948）、气压计（BMP280）、GPS（NMEA）、罗盘（QMC5883L/HMC5883）、返航（RTL）、遥控（iBus）、PID、电机驱动全部为自研代码，位于 `M6_full_flight/src/`，clone 仓库后无需安装任何额外库即可编译。

### 命令行编译（可选）

```bash
# 以 M6 为例（arduino-cli 需已配置 esp32 核心）
arduino-cli compile --fqbn esp32:esp32:esp32s3 "M6_full_flight"
```

## 安全铁律

- 任何电调/电机通电前**必须拆桨**
- 测试顺序：拆桨桌面 → 测试架 → 系留 → 自由首飞
- 接电池时拔 USB，USB 调试时不接电池
- 返航/失控保护属于高风险功能：首次试飞请在开阔场地、无 GPS 拒止环境进行，且必须先完成罗盘磁校准
