# M2 仿真 —— 姿态控制 PID 参数标定

> 本文件夹保存 M2 里程碑的仿真程序与标定结果，供 M6 装机后调参对照。

## 文件说明

| 文件 | 作用 | 运行方式 |
|---|---|---|
| `drone_pid_sim.py` | 四旋翼姿态仿真主程序（外环角度 + 内环角速率 PID） | `python drone_pid_sim.py` |
| `drone_pid_sim.html` | 仿真结果可视化（浏览器打开） | 双击打开 |
| `tune_scan.py` | PID 参数网格扫描（找稳定区间） | `python tune_scan.py` |
| `mahony_sim.m` | Mahony 姿态解算的 Matlab 验证 | Matlab 打开运行 |

## 已标定参数（M2 验收值）

### 控制环
- 外环（角度环）：200 Hz，`KP_ANG = 6.0`，`KP_YAW_ANG = 3.0`
- 角速率限制：`RATE_MAX = 2.5 rad/s`，`YAW_RATE_MAX = 1.2 rad/s`
- 内环（角速率环）：1 kHz，`KP_RATE = [0.36, 0.36, 0.58]`
- 积分：`KI_RATE = [0.08, 0.08, 0.12]`
- 微分：`KD_RATE = [0.008, 0.008, 0.012]`
- 力矩上限：`TAU_MAX = [0.7, 0.7, 0.35] N·m`

### 物理模型
- 质量 `M = 1.8 kg`；惯量 `IXX = IYY = 0.020`，`IZZ = 0.033` kg·m²
- 轴距 `0.450 m`，力臂 `0.225 m`
- 电机一阶滞后 `50 ms`；最大拉力 `F_MAX = 8.0 N`，悬停拉力 `F_HOVER = 4.41 N`
- 推重比 `1.81`

### X 型混控（电机编号与方向）
| 电机 | 位置 | 混控符号 | 旋转方向 |
|---|---|---|---|
| M1 | 右前 | +1（滚转/俯仰） | 正牙（顺时针桨） |
| M2 | 左后 | +1 | 正牙 |
| M3 | 左前 | −1 | 反牙（逆时针桨） |
| M4 | 右后 | −1 | 反牙 |

## ⚠ 装机提醒
- 以上 PID 为**仿真标定值**；装机后必须按实测「油门 → 拉力」关系重标，不可照搬绝对值。
- 实物飞行需先用仿真中的稳定区间做保守起步（更小的 KP/更大的阻尼），再逐步接近标定值。
